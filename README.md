## Проекты

### [prompt-arena](https://github.com/maarshir/prompt-arena)

Прогоняет несколько вариантов промпта по одним и тем же задачам и показывает, где ответы разошлись, а не только средний балл. Готовы проверки ответов и тесты к ним, сейчас доделываю прогон моделей и отчёт.

`python` `pytest` `httpx`

### [Wishly](https://github.com/maarshir/Wishly)

Приложение в Телеграме, чтобы два человека вели общий список желаний: подарки, места и рестораны с фото, ценами и уровнем «хочу». Данные хранятся в общей базе и видны обоим сразу.

`javascript` `supabase` `tailwind`

### [Личный ассистент](https://github.com/maarshir/assistant)

Сайт и бот в Телеграме для контроля режима дня: сон, тренировки, питание, задачи и расходы. Модель разбирает свободные фразы и голосовые в конкретные действия с записями дня, есть напоминания и вечерний разбор.

`python` `fastapi` `postgresql` `llm`
