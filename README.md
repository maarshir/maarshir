## Проекты

### [promptdiff](https://github.com/maarshir/promptdiff-)

Прогоняет несколько вариантов промпта по одним и тем же задачам и показывает расхождения, как diff: на каких задачах один вариант прошёл проверки, а другой нет. Асинхронные запросы с повторами, кэш ответов, цена каждого варианта.

`python` `asyncio` `httpx` `pytest`

### [doc-answers](https://github.com/maarshir/doc-answers)

Отвечает на вопросы по папке со своими документами строго по найденным кускам, со ссылкой на источник, а если ответа нет, так и говорит. Поиск BM25 без векторной базы, ссылки модели проверяются кодом, набор вопросов отдельно проверяет поиск и ответы.

`python` `rag` `bm25` `pytest`

### [token-counter](https://github.com/maarshir/token-counter)

Считает стоимость запросов к моделям: точная денежная арифметика, таблица цен с датой и источником у каждой цены, прикидка до отправки. Им считает цену promptdiff.

`python` `decimal` `cli`

### [Личный ассистент](https://github.com/maarshir/assistant)

Сайт и бот в Телеграме для режима дня: модель разбирает свободные фразы и голосовые в действия с записями дня через JSON, с защитой от ошибок модели и доступом только для владельца.

`python` `fastapi` `postgresql` `llm`

### [Wishly](https://github.com/maarshir/Wishly)

Приложение в Телеграме, чтобы два человека вели общий список желаний: подарки, места и рестораны с фото, ценами и уровнем «хочу».

`javascript` `supabase` `tailwind`
